<h2>v0.0.0-beta.1 — Initial 26.2 Port</h2>

<h3>🚀 Port to Minecraft 26.2</h3>
<p>Player Animation Core has been ported to <strong>Minecraft 26.2</strong> / <strong>NeoForge 26.2.0.32-beta</strong>, starting from the stable 26.1.2 state (<code>1.0.0</code>).</p>

<h3>🛠 Changes</h3>
<ul>
<li><strong>NeoForge 26.2 API</strong> — <code>GameRenderer.getMainCamera()</code> was removed in 26.2; replaced with the new <code>GameRenderer.mainCamera()</code> accessor in <code>ItemInHandRendererMixin</code>, <code>MolangQueries</code> and <code>ClientUtil</code>.</li>
<li><strong>Build tooling</strong> — <code>net.neoforged.moddev</code> updated to <code>2.0.142</code>; the raw <code>templates/</code> folder is excluded from the final JAR so only the resolved <code>META-INF/neoforge.mods.toml</code> is shipped.</li>
</ul>

<h3>✨ Features (from 1.0.0)</h3>
<ul>
<li><strong>Keyframe Animation System</strong> — JSON-based animations with GeckoLib-style keyframes, easing, and layered priority blending.</li>
<li><strong>Four First-Person Modes</strong> — <code>THIRD_PERSON_MODEL</code>, <code>HANDS_ONLY</code>, <code>HANDS_ONLY_ARM</code>, and <code>VANILLA</code>.</li>
<li><strong>Configurable Arm Rotation</strong> — <code>FirstPersonConfiguration</code> with <code>armRotationScale</code>, <code>armLength</code>, and <code>pitchFactor</code>.</li>
<li><strong>Bone Transform API</strong> — Query and apply transforms to any body part, with automatic mirroring for left-hand rendering.</li>
<li><strong>Layered Animation Stacking</strong> — Multiple animations run simultaneously with per-bone priority override.</li>
</ul>
