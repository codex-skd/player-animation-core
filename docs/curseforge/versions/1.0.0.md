<h2>v1.0.0 — First Stable Release for Minecraft 26.2</h2>

<h3>🚀 Stable Release</h3>
<p>Player Animation Core is now <strong>stable</strong> for <strong>Minecraft 26.2</strong> / <strong>NeoForge 26.2.0.32-beta</strong>.</p>

<h3>🛠 Fixes Included</h3>
<ul>
<li><strong>ItemInHandRenderer</strong>: retargeted to <code>submitHandsWithItems</code> (renamed in 26.2).</li>
<li><strong>LevelExtractor</strong>: entity extraction mixin moved from <code>LevelRenderer</code> to the new <code>net.minecraft.client.renderer.extract.LevelExtractor</code> class.</li>
</ul>

<h3>✨ Features</h3>
<ul>
<li><strong>Keyframe Animation System</strong> — JSON-based animations with keyframes, easing, and layered priority blending.</li>
<li><strong>Four First-Person Modes</strong> — <code>THIRD_PERSON_MODEL</code>, <code>HANDS_ONLY</code>, <code>HANDS_ONLY_ARM</code>, and <code>VANILLA</code>.</li>
<li><strong>Configurable Arm Rotation</strong> — <code>FirstPersonConfiguration</code> with <code>armRotationScale</code>, <code>armLength</code>, and <code>pitchFactor</code>.</li>
<li><strong>Bone Transform API</strong> — Query and apply transforms to any body part.</li>
<li><strong>Layered Animation Stacking</strong> — Multiple animations with per-bone priority override.</li>
</ul>
