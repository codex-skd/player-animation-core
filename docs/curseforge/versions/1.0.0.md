<h2>v1.0.0 — First Stable Release</h2>

<h3>🎉 Stable Release</h3>
<p>Player Animation Core reaches version 1.0.0! All features from the beta cycle are now stable and ready for production use.</p>

<h3>✨ Features</h3>
<ul>
<li><strong>Keyframe Animation System</strong> — JSON-based animations with GeckoLib-style keyframes, easing, and layered priority blending.</li>
<li><strong>Four First-Person Modes</strong> — <code>THIRD_PERSON_MODEL</code>, <code>HANDS_ONLY</code>, <code>HANDS_ONLY_ARM</code>, and <code>VANILLA</code> to control how first-person rendering works.</li>
<li><strong>Configurable Arm Rotation</strong> — <code>FirstPersonConfiguration</code> with <code>armRotationScale</code>, <code>armLength</code>, and <code>pitchFactor</code> for per-weapon tuning.</li>
<li><strong>Bone Transform API</strong> — Query and apply transforms to any body part. Automatically mirror animations for left-hand rendering.</li>
<li><strong>Layered Animation Stacking</strong> — Multiple animations run simultaneously with priority per-bone override.</li>
</ul>
